Loading XML ​

XmlStructLoader reads an XML document into the types of a generated module. The document is parsed with pugixml, and the object is built in one pass over it: each element becomes the field of its parent with the same name, and each value is checked against the schema as it is built.

From a module ​

When the generated module is already loaded, pass it to load:

julia
orders = load(orders_xml, Orders)
[order.id for order in orders.order]
2-element Vector{String}:
 "A-1001"
 "A-1002"

The document can also come from any IO, such as a string already in memory:

julia
xml_text = read(orders_xml, String)
load(IOBuffer(xml_text), Orders).order[2].phone
"+31 40 123 4567"

From a path ​

load also takes the path of the generated module, or of the directory holding it, and includes the module itself:

julia
orders = load("orders.xml", joinpath("generated", "orders"))

The module is included into XmlStructLoader once per session under its own name. Later calls with the same module reuse it, and regenerating the module on disk does not replace the one already loaded; restart the session to load new definitions.

import_module_from_xml and use_module_from_xml do the inclusion and return the module, for code that loads several documents or wants the types themselves. use_module_from_xml also re-exports the generated types from XmlStructLoader.

julia
Orders = import_module_from_xml("orders.xml", joinpath("generated", "orders"))
orders = load("orders.xml", Orders)

Including a module inside a running function has a cost: the function cannot see the new types directly, so the loader calls into them with Base.invokelatest. A module that is part of a package does not have this cost, and is precompiled; see Shipping a schema in a package.

Validation ​

By default every value with a restriction in the schema is checked while the document is loaded, and the first violation stops the load. In this document the first order line asks for 0 items, below the schema's minimum of 1:

julia
invalid = replace(xml_text, "<quantity>2</quantity>" => "<quantity>0</quantity>")
try
    load(IOBuffer(invalid), Orders)
catch err
    err
end
AbstractXsdTypes.XSDValueRestrictionViolationError(Main.Orders.Orders_struct.Quantity, 0, "Value 0 is less than the minimum value (1) for Main.Orders.Orders_struct.Quantity.")

validate = false skips the checks, for documents that are known to be valid or that have to be read even though they are not:

julia
unchecked = load(IOBuffer(invalid), Orders; validate = false)
quantity = unchecked.order[1].line[1].quantity
(quantity.value, quantity.__validated)
(0, false)

Each object records in __validated whether it was checked.

These are all the built-in XML Schema types the generator maps; see Limitations for the others.

The attributes of the root element, including its namespace declarations, are kept so that writing the object back produces the same declarations:

julia
orders.__xml_attributes
Dict{String, String} with 3 entries:
  "xmlns:Orders"       => "Orders"
  "xsi:schemaLocation" => "Orders orders.xsd"
  "xmlns:xsi"          => "http://www.w3.org/2001/XMLSchema-instance"

Large documents ​

load builds the whole document. To read parts of a large document, or to count its records without building them, use Lazy loading.
