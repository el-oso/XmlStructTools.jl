XmlStructPugixml.doc_as_node Method
julia

View a document handle (from new_doc or parse_file) as a plain node handle, so it can be passed to append_child_element to attach the document's root element. Do not free this handle separately - it is owned by the document, same as any other node handle.

XmlStructPugixml.node_name Method
julia
node_name(node::Ptr{Cvoid})::String

The node's tag name, e.g. "TestElement1". Never errors; returns "" if the node has no name. Note: pugixml does not split a namespace-prefixed name like "Foo:document" into namespace + local part - the caller gets the literal string as written in the source XML.

XmlStructPugixml.parse_buffer Method
julia
parse_buffer(data::AbstractVector{UInt8})::Ptr{Cvoid}

Parse an in-memory buffer of XML bytes (e.g. read(io) on an arbitrary IO) into a document, returning an owning handle exactly like parse_file. Returns C_NULL on parse failure.

DenseVector rather than AbstractVector: the bytes are handed to pugixml as a pointer plus a length, so a strided view would be read as if it were contiguous. Vector{UInt8} and codeunits(::String) qualify.

source
XmlStructPugixml.parse_file Method
julia
parse_file(path::AbstractString)::Ptr{Cvoid}

Parse the XML file at path into an in-memory pugixml document, returning an owning handle. Call free_doc exactly once on the returned handle when done. Returns C_NULL if the file could not be parsed (bad path, malformed XML).

source
XmlStructPugixml.root Method
julia
root(doc::Ptr{Cvoid})::Ptr{Cvoid}

Return the document's root element node handle, or C_NULL if the document has none.

Throws on a C_NULL document rather than passing it through: the shim dereferences it, so root(parse_file(bad_path)) would otherwise segfault the process.

source

XmlStructPugixml.node_name_ptr Method
julia
node_name_ptr(node::Ptr{Cvoid})::Ptr{UInt8}

The node's tag name as pugixml's own NUL-terminated C string, not copied.

node_name copies those bytes into a Julia String. This hands back the pointer itself, for a caller that wants to intern the name or inspect part of it without paying for the copy. The bytes belong to the parsed document and stay valid only until it is freed.
